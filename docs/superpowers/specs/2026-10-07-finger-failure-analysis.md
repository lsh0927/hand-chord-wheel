# Failure Analysis — 손가락 모드(3차) (2026-10-07)

대상: `2026-10-07-finger-mode-design.md` + 계획 1판. 3개 관점(판정 수학 / 상태 분기 / 엣지·테스트). 결과는 계획 2판(부록)과 구현에 반영.

```
판정 수학   │ GAP 3, NOTE 2
상태 분기   │ GAP 1, NOTE 7
엣지·테스트 │ CRITICAL 1(테스트 모순), GAP 4, NOTE 4
```

## CRITICAL
**C1. 계획의 StableValue 첫 테스트가 구현·설계와 모순.** `update(2, 50)` 뒤 `update(2, 120) → 2`를 기대했지만 후보는 50부터라 170에서 바뀐다. 구현을 테스트에 맞추면 "스침 무시"가 깨진다. → 테스트를 `update(2,169) → 1`, `update(2,170) → 2`로 수정.

## NOTE (반영)
- processFingerFrame에 `now` 전달(시간 출처 하나). 디버그는 손가락 모드에서 `h nn%`. Reset 안내문 모드별. 위치 상자 문구 "위치: …"로 중립화. 높이→음량 지수를 `levelExponent: 1.5`로 config화(실측 때 1/1.5/2 비교). 팔레트 5개 미만 분기는 min=6이라 현재 도달 불가(주석). 주먹을 트래커가 놓치는 빈도·재진입 첫 코드 오발·유예 중 StableValue 타이머는 실측 항목.

## 검증된 사실
좌표계(픽셀 등방·거울 반사 불변), 회전·크기 불변, 왼손 무관(거리 규칙), heightPercent·StableValue 수치, 배지 5개가 세 앵커 모두 캔버스 안(1280×720), HUD·하단 바와 비겹침, 인접 배지 코드명 비겹침, Gain 0 안전, 분기 위치 적절, Reset 대기·applyMode 규칙 유지.
