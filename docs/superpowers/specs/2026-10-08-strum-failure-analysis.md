## 확정 문제와 결정

### 1·3. 예약 전송된 Note On이 즉시 보낸 Note Off·패닉 뒤에 도착해 음이 걸린다 (major)
- 빠른 스트럼은 한 프레임 안의 6줄을 0~33 ms(CPU 모드 107 ms) 시차로 **미래 시각에 예약**한다. 그 사이 코드가 바뀌어 `silence()`→`stop()`이 즉시 Note Off를 보내거나 Reset 패닉(CC123)이 나가면, 예약된 Note On이 그 뒤에 도착해 GarageBand에서 음이 영원히 울린다. Tone 쪽도 `triggerRelease(now)`를 뒤따르는 `triggerAttack(t)`가 덮어 옛 코드 음이 남는다.
- **결정**: 출력이 줄별 마지막 예약 시각 `stringAt`을 기억하고, `stop()`·`panic()`·`dispose()`·`fail()`의 종료 메시지(Note Off·CC123·CC120, Tone은 triggerRelease)를 **`max(지금, 마지막 예약 시각) + 1 ms`에 예약**한다. 종료가 최대 33 ms 늦어질 뿐 걸린 음은 구조적으로 사라진다. 테스트로 고정.

### 6. 오른손이 없으면 매 프레임 `resetHandState()`가 왼손 감지기를 지운다 (major)
- "코드 없이 스트럼하면 줄만 번쩍인다"는 피드백이 첫 사용자 경로(왼손만 먼저 들어 봄)에서 100% 깨진다.
- **결정**: 왼손 상태 초기화를 `resetLeftHandState()`로 분리해 Reset·오류 진입·워치독에서만 부르고, 오른손 '없음' 분기에서는 부르지 않는다. 워치독 조건에 `leftView !== null` 추가.

### 7. 최소 속도 0.2 H/s가 느린 아르페지오를 통째로 버린다 (major)
- 분당 120박 4분음표로 한 줄씩 내리면 0.11 H/s라 교차 검사 전에 버려진다. 떨림(1~3 px/프레임) 차단이 목적인데 느린 연주까지 막는다.
- **결정**: 속도 문턱 대신 **줄별 공간 히스테리시스(재장전 거리)**: 타격 뒤 피크가 그 줄에서 0.012H(720p 기준 8.6 px, 떨림의 약 3배) 이상 떨어진 적이 있어야 다음 타격을 센다. 처음 나타난 손이 줄 바로 위면 떨어질 때까지 장전 안 함. 최소 속도는 0.05로 낮춰 보조 가드만.

### 2·8·5. 손 정체성이 바뀌면 피크가 순간이동해 최대 세기 유령 스트럼 (minor·major)
- 두 손 라벨 뒤바뀜·'좌우 바꾸기' 토글·한 손이 두 손으로 중복 검출되면 피크 점이 한 프레임에 0.5H 이상 점프해 줄을 전부 가로지르고(실제 연주의 8배 속도) 벨로시티 1로 울린다.
- **결정**: ① `StrumDetector`에 프레임당 변위 상한 0.2H(실제 최대 0.06H의 3배) — 넘으면 위치만 갱신하고 타격 없음. ② `selectBothHands`에 연속성 교차 검사(두 손이 서로 상대의 직전 위치에 더 가까우면 그 프레임만 맞바꿈) + 같은 자리 중복 검출(손바닥 거리 < 0.03)이면 왼손 보류. ③ '좌우 바꾸기' 변경 시 `silence()` + 왼손 상태 초기화.

### 4. 왼손이 한 프레임만 사라져도 감지기가 초기화되어 빠른 스트럼 중간 음이 빠진다 (minor)
- 모션 블러로 한 프레임 비면 66 ms(6줄 중 2~3줄)가 무음.
- **결정**: 100 ms 이내의 공백은 잇는다(공백 전 위치 → 재등장 위치 선분으로 교차·속도 계산). 먼 곳 재등장은 ①의 변위 상한이 잡는다.

## minor 18건 — 반영 목록
- 오디오 컨텍스트 일시중지 중 pluck 예약 → 재개 순간 폭발: `ToneOutput.pluck`에 `isRunning()` 가드.
- 불응기 60 ms < 뮤트 홀드 90 ms → 재타격을 뮤트 Note Off가 끊음: 뮤트 홀드 40 ms(더 짧고 둔탁), 뮤트는 dampening 1500 Hz.
- 6줄 합산 클리핑 가능성: 줄 Gain 계수 `stringGain 0.5`(실측 조정). 세기→음량 지수 1.5(패드 모드와 같은 사고).
- 업 스트로크 가벼움: ×0.85.
- `voicing()` 빈 배열은 null로(거짓 안내 방지). 안내문: 두 손이 다 보이는데 왼손이 null이면 "'좌우 바꾸기' 확인" 문구.
- 워치독에 왼손 표시 포함. 좌우 바꾸기 시 초기화(위 ③).
- 보류: 4:3 카메라·낮은 창에서 줄 대역이 패널·미리보기와 겹치는 가능성(Playwright 4:3 스크린샷으로 확인 뒤 필요 시 조정), 빠른 왼손의 handedness 점수 0.7 미만 탈락(실측 뒤 왼손 전용 임계 검토).
