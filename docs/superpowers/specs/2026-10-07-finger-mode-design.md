# Hand Chord Wheel — 3차 설계: 손가락 개수로 코드 고르기 (오른손)

작성일 2026-10-07. 상태: 사용자 승인(구두). 1·2차 위에 얹는 추가 기능. 4차(왼손·파워코드·손별 출력)의 발판.

## 1. 무엇을 만드나

하단에 **선택 방식 상자**("선택: 손가락" / "선택: 휠")를 두고, 손가락 모드에서는 펴진 손가락 수(1~5)로 코드를 고른다. 1 = 검지, 2 = 검지+중지, 3 = +약지, 4 = +소지, 5 = +엄지(활짝). 주먹(0)은 쉼. 음량은 손의 높이(들수록 큼). 같은 코드를 다시 치려면 주먹을 쥐었다 편다. 휠 모드는 그대로 남는다.

### 대표 시나리오
1. 상자가 "선택: 손가락"(기본). 팔레트 앞 5개(B, Em6, A9, D#7, G#m)가 오른쪽 아래에 번호와 함께 부채꼴로 표시된다.
2. 오른손 검지만 펴면 120 ms 뒤 ① B가 파랗게 되고 B가 울린다. 손을 가슴 높이에서 머리 높이로 올리면 음량이 커진다.
3. 중지를 더 펴면(2개) 스쳐 가는 숫자 없이 ② Em6으로 바뀐다. 1 → 3으로 바로 가면 중간의 2는 120 ms를 못 채워 울리지 않는다.
4. 주먹을 쥐면 멈춘다. 다시 검지를 펴면 B가 다시 울린다(재타격).
5. 상자를 "선택: 휠"로 바꾸면 2차까지의 휠 동작으로 돌아간다.

### 범위 밖
- 왼손, 파워코드 보이싱, 손별 출력(4차). 손가락 조합(검지+소지 등)의 구분 — 개수만 센다. 엄지만 편 제스처(0으로 취급).

## 3. 동작 규칙

### 3-1. 손가락 펴짐 판정 (픽셀 좌표)
- 검지·중지·약지·소지: `dist(끝, 손목) > dist(PIP, 손목) × 1.15` 이면 펴짐. 관절 번호: 검지 PIP 6/끝 8, 중지 10/12, 약지 14/16, 소지 18/20. 손목에서의 거리 비교라 손이 기울어도 같다.
- 엄지: `dist(엄지 끝 4, 소지 뿌리 17) > dist(엄지 IP 3, 소지 뿌리 17) × 1.1` 이면 펴짐(접으면 끝이 손바닥 안쪽, 소지 쪽으로 들어온다).
- 두 비율(1.15, 1.1)은 ASSUMPTION — 첫날 `?debug=1`의 손가락별 표시로 실측해 교정.

### 3-2. 개수 규칙
- `four = 검지·중지·약지·소지 중 펴진 수(0~4)`. `count = (four === 4 && 엄지 펴짐) ? 5 : four`.
- 엄지는 네 손가락이 다 펴졌을 때만 센다. 검지 하나를 펴면 엄지가 어중간하게 나와 있어도 1이다(엄지 판정이 가장 불안정하므로 1~3에 영향을 주지 않게).
- 조합은 구분하지 않는다(검지+소지도 2).

### 3-3. 안정화
- 개수가 `holdMs = 120 ms` 동안 같아야 "확정 개수"가 바뀐다. 손이 처음 나타난 첫 프레임의 값은 즉시 확정(지연 없이 시작).
- 1 → 3으로 갈 때 스치는 2는 120 ms를 못 채우므로 울리지 않는다.

### 3-4. 코드·소리
- 확정 개수 n(1~5) → 팔레트 인덱스 n−1. 팔레트가 5개 미만이면 없는 번호는 쉼으로 처리하고 패널에 빈 배지.
- n이 바뀌면 이전 음 Off → 새 음 On(기존 `output.play`). 같은 n 유지면 지속. n = 0(주먹) 또는 손 소실(500 ms 유예 뒤) → 음 놓기, 재무장(armed). 주먹에서 다시 펴면 재타격.
- Reset 대기(armed=false) 규칙은 그대로: Reset 뒤 주먹을 쥐거나 손이 사라져야 다시 소리.

### 3-5. 음량 = 손 높이
- 손바닥 중심의 y(픽셀, EMA α 0.5)로 `percent = clamp((0.85H − y) / (0.60H), 0, 1) × 100`: 바닥 선 85%에서 0%, 높이 25% 선에서 100%.
- `level = (percent/100)²`을 기존대로 Tone 음량·CC11에 넘긴다(MIDI는 `levelToCc`로 제곱을 되돌리므로 CC는 높이에 비례).
- 무음 임계는 두지 않는다(낮게 들어도 작은 소리로 남는다). 15% 미만을 무음으로 하면 바닥 근처에서 뚝뚝 끊기기 때문.

### 3-6. 모드 전환·저장
- 상자 `#mode`: `fingers`(기본) / `wheel`. localStorage `hcw.mode.v1`. 전환 시 음 놓기, 안정화 상태 초기화, 표시 칸 비움.
- 휠 모드 코드는 바꾸지 않는다(분기만).

## 4. 화면
- 손가락 모드: 휠 대신 **배지 5개 부채꼴**(휠 위치 설정을 그대로 씀). 배지 = 원 안에 번호, 아래 코드 이름. 선택 배지는 파랑(무음이면 연하게). 제목 "RIGHT HAND — FINGERS".
- 손 위: 손바닥 점 옆에 현재 "원시 개수"(안정화 전) 작은 숫자. HUD 둘째 상자는 "R HEIGHT nn%".
- `?debug=1`: 손가락별 펴짐 플래그(T I M R P 중 펴진 것만 대문자) + 원시/확정 개수.

## 5. 오류·엣지

| 상황 | 처리 |
|---|---|
| 손이 옆으로 누움·카메라 쪽으로 기울어짐 | 손목 거리 비교는 평면 회전에 불변. 깊이 방향 기울기는 끝이 짧아 보여 판정이 흔들릴 수 있음 → 실측 항목, 비율 교정 |
| 엄지 오판 | 1~3에서는 무시되므로 영향 없음. 4↔5만 흔들릴 수 있음 → 비율 교정, 필요하면 holdMs 150 |
| 개수 전환 중 스침 | 120 ms 안정화 |
| 팔레트 5개 미만 | 없는 번호는 쉼 |
| 손 소실 | 1차 유예 500 ms 규칙 그대로, 복귀 시 StableValue·EMA 초기화 |
| 모드 전환 중 연주 | 음 놓고 상태 초기화 |

## 6. 테스트
- Vitest(`tests/fingers.test.ts`), 합성 손: 활짝(5), 주먹(0), 검지(1), 검지+중지(2), 세 손가락(3), 네 손가락(엄지 접음, 4), 네 손가락+엄지(5), 검지만 + 엄지 벌림(1 — 엄지 무시), 검지+소지(2). 손 전체를 90도 돌려도 결과 동일. StableValue: 첫 값 즉시, 변경은 120 ms 뒤, 119 ms에 되돌아가면 유지 안 바뀜. heightPercent: y=0.85H → 0, 0.25H → 100, 0.55H → 50, 범위 밖 클램프.
- 브라우저(Playwright): 모드 상자 기본값·저장·복원, HUD 라벨 전환, 패널 표시(스크린샷).
- 실측: 손가락 1~5 전환이 의도대로 잡히는지, 엄지·약지 오판 빈도, 높이 음량 체감, 주먹 재타격.

## 7. 실패 분석 반영 (2026-10-07, `2026-10-07-finger-failure-analysis.md`)
- 3-1 판정에 **손가락별 히스테리시스**: 네 손가락 진입 1.20 / 해제 1.10, 엄지 진입 1.18 / 해제 1.05 (`FingerDetector`가 5개 Hysteresis 보유, 손 소실·모드 전환 때 초기화). 수치는 ASSUMPTION — 실측 교정.
- 3-1 추가: 손목(0)·네 뿌리 관절(5·9·13·17)의 정규화 좌표가 [−0.05, 1.05] 밖이면 그 프레임은 판정 보류(직전 확정 개수·소리 유지), 디버그에 "손목 화면 밖".
- 3-5 수정: `percent = max(10, heightPercent)` → 바닥에서도 작은 소리 유지, `level = (percent/100)^levelExponent`(기본 1.5, config). 배지·HUD의 '무음 표시'는 `state !== PLAYING || level < 0.02`.
- 4장: 중앙 안내문은 앵커의 반대편 빈 사분면에 상자로 그린다(패널·휠을 가리지 않게). 위치 상자 문구 "위치: 오른쪽 아래/왼쪽 아래/가운데". 패널 제목 아래 작은 안내 "주먹 = 쉼 · 5 = 엄지를 옆으로".
- 3-4: Reset 안내문(손가락 모드) "주먹을 쥐었다 펴거나 손을 내렸다 올리면 다시 소리가 납니다".
- 6장 테스트 추가: 경계 ratio 히스테리시스 시퀀스, span≤0, 21개 미만 throw, 같은 후보 유지, 테스트 수치 수정(StableValue 170 ms).
